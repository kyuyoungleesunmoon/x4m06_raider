# X4M06 레이더 데이터 수집 시스템 사용 가이드

## 📋 개요
이 시스템은 X4M06 UWB 레이더에서 실시간으로 데이터를 수집하고 저장하는 도구입니다.

## 🔧 시스템 요구사항

### 하드웨어
- X4M06 UWB 레이더 모듈
- USB 연결 케이블
- Windows 10/11 PC

### 소프트웨어
- Python 3.6 환경 (conda 가상환경 권장)
- X4M06 pymoduleconnector 라이브러리
- 필수 패키지: numpy, matplotlib, json

## 🚀 빠른 시작 가이드

### 1단계: 하드웨어 연결
1. X4M06 레이더를 USB 포트에 연결
2. 장치 관리자에서 COM 포트 번호 확인 (보통 COM3)
3. 레이더 모듈이 안정적으로 연결되었는지 확인

### 2단계: 소프트웨어 환경 준비
```bash
# conda 가상환경 활성화
conda activate x4m06_env

# 작업 디렉토리로 이동
cd C:\X4M06_레이더
```

### 3단계: 데이터 수집 실행

#### A. 빠른 데이터 수집 (권장 - 초보자용)
```bash
python easy_data_collector.py
```
- 간단한 메뉴 선택으로 데이터 수집
- 자동 설정 적용
- 안전하고 안정적

#### B. 고급 데이터 수집 (고급 사용자용)
```bash
python x4m06_data_saver.py
```
- 상세한 설정 조정 가능
- 실시간 플롯 옵션
- 커스텀 수집 시간/프레임 수

#### C. 설정 변경
```bash
python config_manager.py
```
- 레이더 파라미터 조정
- COM 포트 설정
- 탐지 범위 변경

## 📊 수집된 데이터 위치
```
C:\X4M06_레이더\collected_data\
├── x4m06_data_[세션ID].json     # 상세 데이터
├── x4m06_data_[세션ID].npz      # NumPy 압축 데이터  
└── summary_[세션ID].txt         # 수집 요약
```

## 🔍 데이터 분석
```bash
python hardware_data_analyzer.py
```
- 저장된 데이터 시각화
- 모션 감지 분석
- CSV 형식 내보내기

## ⚙️ 주요 설정 옵션

### 탐지 범위 설정
- **근거리 (0-2m)**: DAC 900-1000
- **중거리 (0-5m)**: DAC 900-1400 (기본값)
- **장거리 (0-10m)**: DAC 900-1800

### 데이터 수집 설정
- **샘플링 속도**: 10-30 FPS
- **수집 시간**: 10초-10분
- **최대 프레임**: 100-5000개

## 🆘 문제 해결

### 연결 문제
1. COM 포트 번호 확인
2. 다른 프로그램에서 레이더 사용 중인지 확인
3. USB 케이블 교체 시도

### 데이터 수집 문제
1. 가상환경 활성화 확인
2. pymoduleconnector 설치 확인
3. 레이더 리셋 후 재시도
