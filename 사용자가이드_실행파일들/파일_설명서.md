# 📁 사용자 가이드 실행 파일들

이 폴더에는 X4M06 레이더 데이터 수집 시스템의 사용자 가이드에서 언급되는 모든 실행 파일들이 포함되어 있습니다.

## 📋 파일 목록 및 설명

### 🚀 메인 실행 파일들

#### 1. `run_x4m06.bat` ⭐ **가장 추천**
- **설명**: 시스템 전체를 실행하는 Windows 배치 파일
- **용도**: 가장 간단한 실행 방법
- **사용법**: 더블클릭으로 실행
- **특징**: 환경 체크 및 자동 실행

#### 2. `launcher.py` ⭐ **통합 메뉴**
- **설명**: 모든 기능을 통합한 메인 런처
- **용도**: 통합 메뉴에서 원하는 기능 선택
- **사용법**: `python launcher.py`
- **특징**: 환경 검증, 통합 인터페이스 제공

### 🎯 데이터 수집 파일들

#### 3. `easy_data_collector.py` ⭐ **초보자 추천**
- **설명**: 간편한 메뉴 방식 데이터 수집기
- **용도**: 초보자용 데이터 수집
- **사용법**: `python easy_data_collector.py`
- **특징**: 
  - 5가지 사전 설정 모드
  - 자동 설정 적용
  - 실시간 플롯 지원
  - 연결 상태 자동 확인

#### 4. `x4m06_data_saver.py` ⭐ **고급 사용자용**
- **설명**: 상세 설정 가능한 고급 데이터 수집기
- **용도**: 전문가용 데이터 수집
- **사용법**: `python x4m06_data_saver.py`
- **특징**:
  - 명령행 파라미터 지원
  - 상세한 설정 조정 가능
  - 실시간 플롯 옵션
  - 커스텀 수집 시간/프레임 수

### ⚙️ 설정 및 관리 파일들

#### 5. `config_manager.py`
- **설명**: 시스템 설정 관리 도구
- **용도**: 레이더 파라미터 및 시스템 설정
- **사용법**: `python config_manager.py`
- **특징**:
  - 레이더 파라미터 조정
  - COM 포트 설정
  - 탐지 범위 변경
  - 설정 저장/불러오기
  - 사전 설정 관리

#### 6. `quick_test.py`
- **설명**: 빠른 연결 테스트 도구
- **용도**: 레이더 연결 상태 확인
- **사용법**: `python quick_test.py`
- **특징**:
  - 하드웨어 연결 확인
  - COM 포트 테스트
  - 기본 통신 검증

### 📊 데이터 분석 파일들

#### 7. `hardware_data_analyzer.py`
- **설명**: 수집된 데이터 분석 도구
- **용도**: 데이터 시각화 및 분석
- **사용법**: `python hardware_data_analyzer.py`
- **특징**:
  - 저장된 데이터 시각화
  - 모션 감지 분석
  - CSV 형식 내보내기
  - 통계 정보 제공

### 📖 문서 파일들

#### 8. `README_사용가이드.md` ⭐ **필수 읽기**
- **설명**: 완전한 사용자 가이드 문서
- **용도**: 처음부터 설치 및 사용 방법

  - 상세한 문제 해결 방법
  - 자주 묻는 질문 (FAQ)
  - 체크리스트

#### 9. `FINAL_README.md`
- **설명**: 프로젝트 전체 개요 문서
- **용도**: 시스템 전체 구조 이해
- **내용**:
  - 시스템 개요
  - 설치 방법
  - 사용 방법
  - 구성 요소 설명

## 🔄 권장 사용 순서

### 처음 사용하는 경우:
1. **`README_사용가이드.md`** 읽기 ← **필수**
2. **가상환경 및 라이브러리 설치** (가이드 따라)
3. **`quick_test.py`** 로 연결 테스트
4. **`run_x4m06.bat`** 더블클릭으로 시작

### 일반적인 사용:
1. **`run_x4m06.bat`** 더블클릭 ← **가장 간단**
2. 또는 **`launcher.py`** 실행
3. 메뉴에서 원하는 기능 선택

### 문제 해결:
1. **`README_사용가이드.md`** 의 "문제 해결" 섹션 참조
2. **`quick_test.py`** 로 연결 상태 확인
3. **`config_manager.py`** 로 설정 점검

## 📁 필요한 추가 폴더들

이 파일들이 제대로 작동하려면 메인 프로젝트 폴더에 다음 폴더들이 있어야 합니다:

- `collected_data/` - 수집된 데이터 저장 위치
- `logs/` - 로그 파일 저장 (자동 생성)
- pymoduleconnector 라이브러리 (별도 설치 필요)

## ⚠️ 중요 사항

1. **Python 3.6 환경 필수** - 다른 버전 사용 시 DLL 에러 발생
2. **conda 가상환경 권장** - `conda activate x4m06_env`
3. **X4M06 하드웨어 연결 필수** - 보통 COM3 포트
4. **관리자 권한 필요할 수 있음** - 파일 저장 시
