# 🎯 X4M06 레이더 시스템 - 독립 실행 패키지

이 폴더는 X4M06 레이더 데이터 수집 시스템을 위한 **완전한 실행 패키지**입니다.

## 📦 패키지 내용

이 폴더에 포함된 모든 파일들은 사용자 가이드에서 언급되는 핵심 실행 파일들입니다:

### 🚀 **실행 파일들**
- `run_x4m06.bat` - 메인 실행 파일 (더블클릭)
- `launcher.py` - 통합 메뉴 시스템
- `easy_data_collector.py` - 초보자용 데이터 수집기
- `x4m06_data_saver.py` - 고급 데이터 수집기
- `config_manager.py` - 설정 관리자
- `hardware_data_analyzer.py` - 데이터 분석기
- `quick_test.py` - 연결 테스트 도구

### 📖 **문서 파일들**
- `README_사용가이드.md` - **필수** 완전한 사용 가이드
- `FINAL_README.md` - 프로젝트 전체 개요
- `파일_설명서.md` - 각 파일 상세 설명
- `빠른_실행_가이드.txt` - 빠른 참조 가이드
- `requirements.txt` - Python 패키지 목록

## 🔄 이 폴더만으로 실행하기

### ✅ 준비사항 (한 번만)

1. **Python 3.6 가상환경 생성**
   ```bash
   conda create -n x4m06_env python=3.6
   conda activate x4m06_env
   ```

2. **필수 패키지 설치**
   ```bash
   pip install -r requirements.txt
   ```

3. **pymoduleconnector 설치** (별도 필요)
   ```bash
   # X4M06 패키지의 python36-win64 폴더에서:
   python setup.py install
   ```

4. **하드웨어 연결**
   - X4M06을 USB 포트에 연결
   - COM 포트 번호 확인 (보통 COM3)

### 🚀 실행하기

#### 방법 1: 배치 파일 (가장 간단)
```bash
# 이 폴더에서:
run_x4m06.bat
```

#### 방법 2: Python 직접 실행
```bash
# 가상환경 활성화
conda activate x4m06_env

# 이 폴더로 이동
cd "사용자가이드_실행파일들"

# 실행
python launcher.py
```

## 📁 데이터 저장 위치

데이터는 **이 폴더 내**에 자동으로 생성되는 `collected_data` 폴더에 저장됩니다:

```
사용자가이드_실행파일들/
├── collected_data/          # 자동 생성됨
│   ├── x4m06_data_*.json   # 수집된 데이터
│   ├── x4m06_data_*.npz    # NumPy 압축 데이터
│   └── summary_*.txt       # 수집 요약
├── logs/                   # 자동 생성됨
└── (실행 파일들...)
```

## ⚠️ 중요한 참고사항

### 🔍 **이 폴더만으로는 부족한 것들**

이 폴더는 **실행 파일들만** 포함하고 있습니다. 완전한 작동을 위해서는:

1. **pymoduleconnector 라이브러리** 별도 설치 필요
   - X4M06 패키지의 `python36-win64` 폴더에서 설치
   
2. **Python 3.6 환경** 필수
   - 다른 Python 버전에서는 DLL 에러 발생

3. **X4M06 하드웨어** 필요
   - 실제 레이더 모듈 연결 필요

### 📋 **문제 발생 시**

1. **`README_사용가이드.md` 파일 먼저 읽기** ← **필수**
2. "처음부터 완전 설치 가이드" 섹션 참조
3. "문제 해결" 섹션에서 해결책 찾기
